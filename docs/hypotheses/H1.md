# Hypothesis 1: Dynamic and Action-Aware Memory Retrieval

## 1. Hypothesis
The fixed/predefined memory retrieval strategy in Ctrl-World may not select the most relevant historical information for every current state and future action. A **dynamic, action-aware memory retrieval mechanism** could improve temporal consistency, action controllability, and long-horizon prediction while keeping the memory budget fixed.

## 2. Motivation
Ctrl-World already uses memory retrieval. The goal is **not to introduce memory from scratch**, but to improve how relevant historical frames are selected for the current prediction context.

A fixed retrieval strategy may retrieve useful past frames for one action but less relevant frames for another. Retrieval that adapts to the current robot state, object state, and upcoming actions may provide more useful context to the generator.

## 3. Individual Components

### A. Current Robot State
Use the current robot pose or state as a retrieval signal. Historical frames with similar robot configurations may be useful for predicting the next scene.

### B. Object State
Use object position, pose, configuration, or interaction state to retrieve memories relevant to the objects currently involved in the task.

### C. Upcoming Action Sequence (Action-Aware Retrieval)
Condition memory retrieval on the planned/current action sequence. The same scene state may require different historical memories depending on what the robot is about to do.

### D. Visual Relevance
Consider visual similarity between the current observation and candidate historical frames to retrieve memories with relevant scene appearance or configuration.

### E. Temporal Relevance
Use temporal distance or recency as a possible signal, balancing recent context with older but potentially more relevant memories.

### F. Prediction Uncertainty (Optional Extension)
If the model's prediction uncertainty can be estimated, use it as an additional signal to adapt memory selection or retrieval strength when the prediction is uncertain.

## 4. Proposed Retrieval Mechanism

For each candidate memory \(m_i\), compute a relevance score conditioned on the current query/state and upcoming actions:

\[
S(m_i \mid q_t, a_{t:t+H}) =
\lambda_p S_{pose}
+ \lambda_o S_{object}
+ \lambda_a S_{action}
+ \lambda_v S_{visual}
+ \lambda_t S_{temporal}
+ \lambda_u S_{uncertainty}
\]

The weights may initially be fixed and later explored as learned or dynamically adjusted weights. Select or weight the top relevant memories under a **fixed memory budget**, then pass them to the existing Ctrl-World generation pipeline.

## 5. Proposed Pipeline

1. Receive the current observation and robot state.
2. Encode the current scene/object state and upcoming action sequence.
3. Score candidate historical memories using the retrieval signals.
4. Select or weight the most relevant memories under a fixed memory budget.
5. Feed the retrieved memories into the world model.
6. Generate the future frames conditioned on actions and retrieved context.

## 6. Experimental Variants

| Variant | Retrieval Strategy |
|---|---|
| E0 | Original Ctrl-World memory retrieval |
| E1 | Fixed/sparse memory baseline |
| E2 | Dynamic pose-based retrieval |
| E3 | Pose + object-state retrieval |
| E4 | Pose + object state + upcoming action (main hypothesis) |
| E5 | E4 + uncertainty-adaptive retrieval (optional) |

## 7. Evaluation

Evaluate the variants using:

- **Temporal consistency:** stability across generated frames and reduced drift.
- **Action controllability:** whether generated futures follow the intended actions.
- **Object-state consistency:** whether object states and interactions remain coherent.
- **Long-horizon performance:** quality and consistency over longer predictions.
- **Prediction quality:** suitable visual prediction metrics (e.g., PSNR, SSIM, LPIPS, or FVD, depending on the evaluation setup).
- **Memory efficiency:** performance with the same number of retrieved frames/memories.

## 8. Main Experimental Principle
Keep the memory budget constant across comparisons. This helps determine whether improvements come from **better memory selection**, rather than simply providing more historical frames.

## 9. Research Question
**Can dynamically retrieving historical memories based on the current state and intended actions improve controllable world-model prediction compared with Ctrl-World's existing retrieval mechanism?**

## 10. Novelty Caution
Ctrl-World already has a memory retrieval mechanism. The potential contribution is therefore the **adaptive, state- and action-aware retrieval strategy**, not memory itself. A literature review is needed before claiming novelty.
